PatrickOS Recovery

A personal desktop tool for encrypted backup and verified restoration of PatrickOS project source and explicitly selected durable project data.

How it works

The owner prepares a recovery pack containing Git source history, selected project data and restore instructions. Restic encrypts the pack on the owner's computer. Rclone transfers the encrypted backup files to the owner's Google Drive account. Recovery downloads and checks those files before reconstructing source and project data.

Why Google Drive access is requested

The application requests the limited drive.file permission. It uses this permission to create, read, update and delete backup repository files created by, or explicitly authorized for, this application. It reads their metadata to locate backups and verify restoration. The permission does not give general access to unrelated Drive files.

This is a personal recovery tool, not a public storage service. Backup contents are not published on this website.

Privacy and control

Google Drive data is used only for backup, integrity checking, restoration and owner-authorized maintenance. It is not sold, used for advertising or used to train AI models. Read the PatrickOS Recovery privacy policy for storage, retention and access details.

For questions, use the support email shown in the Google authorization screen for this application.
